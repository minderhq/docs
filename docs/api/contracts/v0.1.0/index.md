# MindHub contracts v0.1.0

The public MindHub contracts at tag `contracts-v0.1.0`, published automatically from MindHub's source of truth. Do not edit these files here: changes arrive with the next contracts tag.

Public consumers (the Minder client and CLI, third-party publishers) build against these files. Nothing here is secret: security comes from keys, not from hiding the format.
